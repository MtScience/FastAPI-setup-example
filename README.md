# FastAPI setup example

Пример настройки микросервиса на FastAPI. Описывает гипотетическую организационную структуру. Поддерживает инварианты:
- отсутствие циклов в дереве отделов,
- уникальные названия отделов в пределах родительского отдела (при помощи `UniqueConstraint`),
- сотрудники приписаны только к существующим отделам (при помощи `ForeignKey`).

Реализованы тесты (при помощи pytest), миграции (Alembic), контейнеризация (Docker Compose). Для проекта также настроены
линтер (flake8), форматтер (black) и статический анализатор (MyPy).

## Запуск

1. Создать файл `.env` по аналогии с приведённым `.env.example`.
2. Запустить `make start` или `make start_bg` (для работы в фоновом режиме). Остановка запущенного в фоне сервиса 
   выполняется через `make stop`.
